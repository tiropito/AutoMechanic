Автомеханик

Игра-симулятор автомеханика на Unity 6.3 (WebGL).

Стек: Unity 6.3, C#, DOTween, Plugin Your Games 2.0

Архитектура: Проект построен по компонентному принципу: игровая логика разделена на 9 менеджеров(Economy, Inventory, Slot, Garage, Diagnostic, Repair, Shop, Upgrade, Collection), ScriptableObject данные,
Взаимодействие - через события C# (`event Action`). Статические данные хранятся в `ScriptableObject`.

Игровые механики

 Слоты заказов с рефиллом и бонусными машинами
 Система редкостей: Common / Uncommon / Rare / Epic (детали), Basic / Medium / Premium / Luxury / Secret (машины)
 Взвешенное выпадение поломок
 Коллекция отремонтированных машин с прогрессией разблокировки
 Экономика с апгрейдами гаража


Лицензия: MIT (только исходный код, ассеты не входят)
